Reliability Features:
  - Retry with exponential backoff (3 attempts, capped wait)
  - Rate limiting (30 req/min per client IP)
  - Circuit breaker (opens after 5 failures, 30s recovery)
  - Fallback provider (automatic switch on primary failure)
  - Structured error responses (503/429/500 with details)
  - Response caching (LRU, 256 entries, 5min TTL)
  - Background ingestion (non-blocking)
  - Request ID tracking (X-Request-ID header)
  - Response time tracking (X-Response-Time header)

Deployment Options:
  - docker compose up (full stack)
  - docker compose --profile ollama up (with local fallback LLM)
  - Azure Container Apps / AWS ECS / Google Cloud Run
